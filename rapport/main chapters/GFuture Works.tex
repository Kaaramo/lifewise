Plusieurs prolongements sont déjà identifiés, que le temps du projet ne permet pas de traiter.

\begin{itemize}
  \item Étendre le principe aux deux autres situations du scénario global : le travail et les déplacements.
  \item Ajouter le dialogue avec l'assistant, pour qu'il réponde à des questions sur l'historique (« Comment ai-je organisé mon temps cette semaine ? »).
  \item Intégrer les capteurs que le scénario pilote n'utilise pas : microphone, centrale inertielle, localisation.
  \item Proposer un export de l'historique vers un outil d'analyse comme Power BI.
\end{itemize}
